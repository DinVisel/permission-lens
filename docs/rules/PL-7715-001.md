# PL-7715-001 — Unrecognized permission type

**Severity:** high
**Confidence:** certain
**Needs chain data:** no

## Condition

The request's `permission.type` isn't one of the types this build
recognizes (pinned against MetaMask's `@metamask/7715-permission-types`,
see the note in [`rules/7715.ts`](../../packages/core/src/rules/7715.ts)).

## Why it matters (LEARNING.md §8.4)

ERC-7715 permission types are open-ended strings — different wallets
support different sets. An unrecognized type isn't necessarily malicious,
but this build has no basis for describing what it actually grants.

## What to do

Treat an unrecognized permission type the same as any other "unknown":
don't assume it's narrow just because it looks like one of the known
allowance/stream/periodic shapes. If it's a legitimate new type, consider
contributing a decoder.
