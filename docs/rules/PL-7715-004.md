# PL-7715-004 — Not adjustable

**Severity:** info
**Confidence:** certain
**Needs chain data:** no

## Condition

The permission's `isAdjustmentAllowed` is `false`.

## Why it matters

Informational — the user (or wallet UI) can't narrow this permission's
scope before granting it. It's all the requested scope, or nothing.

## What to do

Nothing required. Worth surfacing in a signing UI so the user knows they
can't negotiate the scope down.
