# PL-7702-010 — Already unusable

**Severity:** info
**Confidence:** certain
**Needs chain data:** yes (the account's current nonce)

## Condition

The authorization's tuple nonce is behind the account's current on-chain
nonce.

## Why it matters

Nothing — informational only. The account's nonce has already moved past
this authorization's, so it can no longer be applied. It's dead.

Nothing. Listed for completeness, not as a warning.
