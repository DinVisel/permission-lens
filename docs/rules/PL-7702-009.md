# PL-7702-009 — Pre-signed for later use

**Severity:** medium
**Confidence:** certain
**Needs chain data:** yes (the account's current nonce)

## Condition

The authorization's tuple nonce is more than 1 ahead of the account's
current on-chain nonce.

## Why it matters

This authorization can't be used yet — the account's nonce has to catch up
first, which happens as the account sends more transactions. That means it
was signed to be held and used at some point in the future, not applied
immediately. If you don't remember signing something for later use, that's
worth asking about.

## What to do

Confirm you (or whoever you trust with this signature) actually intends to
use it later. If not, nothing on-chain needs to happen — an authorization
that never gets submitted never takes effect.
