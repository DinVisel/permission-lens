# PL-7702-003 — Unrecognized code

**Severity:** high
**Confidence:** certain
**Needs chain data:** no

## Condition

The delegate address is not present in the registry under any status.

## Why it matters

Nothing is known about what this code does with the account. Unknown is
always treated as risky, never as "probably fine" — see
[the "unknown means unknown" UX rule](../../IMPLEMENTATION_PLAN.md#8-output-and-ux-rules).

## What to do

Verify the delegate independently (read its source, check who deployed it)
before signing, or ask the vendor to submit it to the registry — see
[`GOVERNANCE.md`](../../GOVERNANCE.md).
