# PL-7710-003 — No expiry

**Severity:** medium (high if combined with no value/target limit — see [PL-7710-005](PL-7710-005.md))
**Confidence:** certain
**Needs chain data:** no

## Condition

The delegation has at least one caveat, but none of them is a decoded
`TimestampEnforcer` restriction with a `before` bound (or the only time
caveat present has `before == 0`, i.e. "no upper bound").

## Why it matters

Without a time bound, this delegation stays valid indefinitely — until
someone remembers to revoke it on-chain (which costs gas). A forgotten,
still-valid delegation is a standing liability.

## What to do

Prefer delegations with an explicit expiry. If none is set, note the
revocation method and consider revoking manually once the delegation is no
longer needed.
