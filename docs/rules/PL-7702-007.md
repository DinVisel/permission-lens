# PL-7702-007 — Delegate is a proxy

**Severity:** medium
**Confidence:** certain
**Needs chain data:** yes (proxy detection: EIP-1967 storage slot / EIP-1167 bytecode pattern)

## Condition

`@permissionlens/onchain`'s `enrich()` identified the delegate as a proxy
(currently pointing at `facts.proxyImplementation`, when known).

## Why it matters

You're not really reviewing the code that will run — you're reviewing a
pointer to it. Whoever controls the proxy's upgrade mechanism can change
what runs behind this address at any time, without you signing anything
new. The implementation being reviewed today may not be the implementation
in effect tomorrow.

## What to do

Find out who can upgrade the proxy (an owner EOA? a timelock? a DAO vote?)
and how much you trust them — that's the real question, more than what the
current implementation does.
