# PL-7710-001 — No caveats — unrestricted authority

**Severity:** critical
**Confidence:** certain
**Needs chain data:** no

## Condition

The delegation's `caveats` array is empty.

## Why it matters

In ERC-7710, every restriction lives in a caveat — there is no other
mechanism. No caveats means the delegate can act as the delegator with no
limits at all: any contract, any amount, any number of times, forever
(until revoked on-chain).

## What to do

Confirm this is intentional (some legitimate use cases genuinely want full
delegation, e.g. a co-owner). If not, the request should include caveats —
ask the dapp why it didn't add any.
