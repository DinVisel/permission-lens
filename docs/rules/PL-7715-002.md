# PL-7715-002 — No expiry rule

**Severity:** high
**Confidence:** certain
**Needs chain data:** no

## Condition

The request's `rules` array has no entry with `type: "expiry"`.

## Why it matters

Without an expiry rule, the requested permission has no time bound at
all — if granted as requested, it stays valid indefinitely.

## What to do

Prefer requests that include an expiry. If the dapp didn't ask for one,
consider whether the wallet should add one by default before granting.
