# PL-7702-004 — Recognized code

**Severity:** info
**Confidence:** certain
**Needs chain data:** no

## Condition

The delegate matches a registry entry with `status: recognized`.

## Why it matters

This is the positive case: the delegate is a known implementation with
vendor-controlled evidence and two maintainer approvals (see
[`GOVERNANCE.md`](../../GOVERNANCE.md)). It is still not a safety guarantee —
see rule 1 in [§8](../../IMPLEMENTATION_PLAN.md#8-output-and-ux-rules): this
library never says "safe."

## What to do

Review the other findings on this grant; a recognized delegate can still have
no time bound, no chain restriction, or other properties worth knowing about.
