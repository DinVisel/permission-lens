# PL-7702-006 — No code at the delegate yet

**Severity:** high
**Confidence:** certain
**Needs chain data:** yes (`eth_getCode` on the target chain)

## Condition

`@permissionlens/onchain`'s `enrich()` fetched the delegate address's code
on the target chain and found none (`facts.codeAt === "0x"`).

## Why it matters

The signature is still valid — someone could deploy code to that address
later (deliberately, or via a CREATE2 collision) and inherit whatever
authority this authorization grants, without you signing anything again.

## What to do

Treat this the same as an unrecognized delegate ([PL-7702-003](PL-7702-003.md)):
there's nothing to review yet, and there might never be — or there might be
something you didn't expect, later.
